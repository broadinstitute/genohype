# Legacy decoder test sources

The repository root is a virtual Cargo workspace, so Rust files in this
directory are not discovered by `cargo test`. They predate the split into the
`genohype-core` and `genohype-cli` crates and are retained as decoder debugging
references while their fixtures are reviewed.

Active integration tests belong in the crate they exercise. The two
self-contained tests formerly stored here have moved to `core/tests/`.

The remaining files fall into two groups:

- `test_01_*`, `test_03_*`, and `test_07_*` through `test_10_*` use Hail tables
  generated by `test_hail_data/`.
- The other files refer to the old, unversioned `data/gene_models_hds` table and
  should not be enabled in CI without replacing that dependency with a small,
  checked-in fixture.

Do not add new tests to this directory; add them under the appropriate crate.
